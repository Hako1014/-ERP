# 电商 ERP 用户手册（首版）

本手册按当前前端菜单和已实现业务流程编写。菜单由角色权限控制；看不到某一模块时，请联系管理员核对角色和数据范围，不要借用他人账号。

## 登录与首页

1. 使用分配的账号或手机号及密码登录。忘记密码时进入找回密码流程；本地调试环境可在严格限定的开发模式看到 mock 验证码，正式环境不显示。
2. 首页看板查看订单金额、订单数、库存预警、客户增长及趋势。数据短时缓存约 15 秒，刚保存业务单据后可稍候刷新。
3. 退出或长时间离开工作台时结束会话。涉及财务、权限和库存调整的操作会留下审计记录。

## 基础资料准备

在“基础设置”维护公司、店铺、物流工具、供应商和客户；在“商品管理”维护商品、规格、组合商品；在“库存管理”维护仓库、区域和库位。仓库与库位、商品 SKU、店铺等基础资料应先准备，再进行采购入库和订单履约。

## 采购与库存

1. “采购管理”中从采购计划创建或维护采购订单，按业务流程提交、审核；需要预付款、采购退货、采购发票或付款时进入对应子菜单办理。
2. 到货后在“库存管理 → 采购入库”登记入库及上架。库存查询、店铺库存、库存预警和出入库查询用于核对数量；调拨、盘点和库存调整应按审批要求操作。
3. 库存结存和成本结果涉及财务口径，结存前应先核对出入库与异常单据。不要直接修改数据库库存值。

## 订单履约

1. “订单管理 → 新订单/待处理订单”核对订单和审核状态。当前平台抓单为 mock 接口，真实平台订单不会自动进入系统。
2. 在“波次管理”按仓库、物流等策略生成波次。按库位排序时会考虑拣货优先级、区域顺序及行/列/层；未配置时按库位编码排序。
3. 在“待打印订单”选择可打印订单，生成批次及面单、拣货单、配货单等 PDF。物流取号当前为手工/本地号码或 mock，带 `MOCK-` 的运单号不能用于真实发货。
4. 在“待发货订单”按界面要求扫描、核对后出库；已发货订单可查看包裹与平台回传留痕。平台回传当前为 mock，不代表外部平台确认。
5. 退货、换货及售后登记在“直营退货订单”等对应页面办理，先核对原订单和货品状态。

## 审批与财务

“协同办公 → 审批管理”配置审批流程，“我的审批”处理本人待办。财务菜单提供会计科目、项目核算类别、凭证、付款/收款、费用、结算、收入、供应商余额和发票等功能。提交、审核、反审核可能受状态和权限限制；操作前核对公司、金额、关联单据及审批记录。金蝶同步当前仅为接口与 mock，不应据此认为真实财务系统已入账。

## 角色 AI 助手

登录后可在页面浮窗打开 AI 助手；助手入口和推荐问题由当前角色权限决定。可询问当前模块的操作方法，并在权限允许时请求只读业务查询。涉及业务数据的回答会显示来源；请通过来源页面复核后再据此处理业务。助手不代替 ERP 的权限校验、审批或业务页面。

当前仅开放采购计划快捷录入，入口受 `purchase:create` 权限控制（系统管理员和采购员）。可用自然语言或粘贴表格生成临时草稿；解析、追问和预填都不会创建单据。请在采购计划原表单核对供应商、商品、规格、单位、数量和价格，并由你点击“生成计划”后才会保存。成功后以页面显示的真实单号和状态为准；新建计划不会自动提交审批、审核、下单、入库、付款或改变库存。

其他单据类型、已保存单据修改及进一步业务执行目前未开放。模型不可用、回答中断或数据范围不允许时，以页面和后端返回为准；保存结果不确定时先查询原请求结果，不要更换请求内容后重复创建。不要向助手输入密码、验证码、API 密钥或不必要的个人敏感信息。

## 站内消息与提醒

点击页头铃铛查看最近消息，选择“查看全部”进入消息中心。可按审批、业务、预警及已读状态筛选；打开消息详情后点击“标记已读”或“全部已读”。消息只对本人且当前仍有单据权限的账号开放，管理员不会自动收到所有人的消息。

审批提交及步骤变化提醒当前审批人，通过/驳回结果通知有权查看的制单人；采购订单到货进度由已批准的入库事件通知相关人员。点击“打开单据 / 待办”仍会重新检查权限。收到在线弹窗、标记已读和实际完成审批是三件不同的事；已读不会自动办理业务。

离线期间消息保留在服务器，恢复连接后自动同步；多标签页会同步已读和未读数。账号停用、权限撤销或待办解除后，旧消息可能隐藏；退出或切换账号后不会保留旧账号正文。网络中断时也可在恢复后刷新消息中心核对，不以是否出现弹窗判断业务是否成功。

审批超时提醒需管理员明确配置规则后才启用，目前生产默认关闭。采购超期和库存不足的定时通知尚缺交期/公司隔离与接收规则，不会默认推送；外部渠道、个人偏好和保留期限管理暂未提供界面。

## 常见问题

- 页面显示 401/登录过期：重新登录；仍失败请管理员核对员工状态。
- 页面显示 403：检查角色权限、部门/公司数据范围和公司 IP 白名单。
- 列表看不到预期数据：先核对筛选条件、单据状态及本人的数据权限。
